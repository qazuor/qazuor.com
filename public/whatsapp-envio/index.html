Envío individual por WhatsApp

Pegá el CSV, cargá tres variantes del mensaje y abrí cada contacto con su texto ya preparado. El envío final lo hacés vos dentro de WhatsApp.

1. Contactos CSV

Se acepta encabezado o no. Ejemplos válidos: telefono,name, 5493442123456,Juan, o simplemente 5493442123456. El teléfono se normaliza quitando espacios, +, guiones y paréntesis.

2. Mensajes

Podés usar {{name}}. Si el contacto tiene nombre, se reemplaza. Si no tiene, se elimina junto con espacios sobrantes. A cada contacto se le asigna una de las tres variantes de forma pseudoaleatoria y estable.
