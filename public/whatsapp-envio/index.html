Envío individual por WhatsApp

Configurá los contactos y mensajes, y después trabajá desde la lista de envío.

Contactos CSV

Se acepta encabezado o no. Ejemplos válidos: telefono,name, 5493442123456,Juan Pérez, o simplemente 5493442123456. El teléfono se normaliza quitando espacios, +, guiones y paréntesis.

Mensajes

Podés cargar 1, 2 o 3 mensajes. Si cargás uno se usa para todos; con dos se reparten aproximadamente 50/50; con tres, aproximadamente un tercio para cada uno. La asignación es estable por teléfono. También podés usar {{name}}.
